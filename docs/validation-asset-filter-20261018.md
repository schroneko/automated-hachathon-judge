# 素材ファイルの取得前除外の検証

2026年10月18日、SVGを含む画像・音声・動画・フォント・3D素材・既知のモデルバイナリ・生成ソースマップを、Git treeの列挙時に拡張子で除外しました。対象blobの取得、ソース容量集計、モデルへの送信より前に適用します。大文字・小文字を区別しません。

HTML・CSS・JSX・Vue内のSVGと素材参照、シェーダー、未知のUTF-8テキスト、汎用の `.map` は保持します。モデル重みとソースの両方に使われる `.pt`・`.pth` は拡張子だけでは除外せず、従来のバイナリ判定を使います。参加者の除外設定やGit属性は適用しません。

## 実APIの検証

公開環境の初回検証は3件ともDecisions APIの採点とGPT-6.1 Sol mediumの理由生成まで完了しました。点数は524が20点、x-cloneが20点、snap-and-packが22点でした。全件がルーブリックv3、全文証拠、固定SHA・ソースハッシュの維持を満たし、理由側の要確認フラグも保持しました。

追加除外で証拠が変わった524だけ、同じコミットの除外後の全文を両APIへ渡して再検証しました。Decisionsは0 / 8 / 8 / 6、合計22点。Sol mediumは点数・SHA・ソースハッシュ・攻撃判定を維持して理由を生成し、要確認を記録しました。初回理由のSHA形式エラーは拒否され、費用を精算した後、採点をやり直さず理由だけ1回再実行しました。初回失敗を含む実費は$0.625838、未精算予約は0です。公開済みの20点は過去の証拠に対する履歴として保持し、今回の22点で上書きしていません。

除外後の524のソースハッシュは `c96794d19527fcc369baafe0b34df9d9a78e83c1b07d01c4021c29ccc03f0981`。Decisionsの保守的な入力上限は248,166トークンで、SVGを重複参照で残した直前の実API検証の588,109トークンから削減できました。単一試行の結果であり、素材除外による採点精度や点数の安定性を保証するものではありません。
